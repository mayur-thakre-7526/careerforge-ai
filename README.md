# 🚀 CareerForge AI

### AI-Powered Career Preparation Platform

CareerForge AI is a full-stack web application designed to help job seekers prepare for their dream jobs using Artificial Intelligence. It aims to simplify resume analysis, identify skill gaps, and provide personalized interview preparation.

The project combines **MERN Stack technologies with Generative AI** to explore practical AI integration in a real-world application.

## ✨ Features

- 🔐 **User Authentication** — Secure user registration and login.
- 📄 **Resume Analysis** — Upload and analyze resumes.
- 🎯 **Job Description Analysis** — Understand job requirements.
- 🔍 **Skill Gap Detection** — Identify missing skills based on job requirements.
- 🤖 **AI Interview Preparation** — Generate relevant interview questions using AI.
- ✍️ **Resume Optimization** — Assist in tailoring resumes to specific job descriptions.

*Features will be updated as development progresses.*

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/mayur-thakre-7526/careerforge-ai.git
cd careerforge-ai
```

### 2. Set Up the Backend

```bash
cd backend
npm install
```

Create a `.env` file inside the backend directory and configure the required environment variables.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET_KEY=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
```

Use the exact environment variable names expected by your application. Never commit your actual secrets to GitHub.

Start the backend using the script configured in `package.json`.

### 3. Set Up the Frontend

Open a separate terminal:

```bash
cd frontend
npm install
npm run dev
```

*Ensure the frontend and backend dependencies and scripts are configured before running these commands.*
